## 4. Things learned in the cloud session — carry these forward

### 4.1 Bug to avoid — `shift_pool` extractor head with 256-bit non-redundant config
The cloud session first attempted hardening with `extractor_mode="shift_pool"`. BER immediately went to 0.5 and stayed there (`dscsp_v5_interrupt_024086.pt` is that dead run).

**Why:** `shift_pool` runs a 5×5 max-pool over the spatial feature map before the 1×1 head. With `num_bits=256` and no redundant coder, each of the 256 output bits now aggregates evidence over a max'd neighborhood that overlaps with adjacent bits — the per-bit channel gets scrambled. `shift_pool` was designed with the 32-bit redundant-coded extractor in mind, where each message bit is spread across many physical bits with voting.

**Fix used in run 2:** Reverted to `extractor_mode="spatial_map"`. Training recovered normally.

**If you want `shift_pool` for crop robustness (item B2a):** either (a) keep `use_redundant_coding=True` with `message_bits << num_bits` (e.g. 32 msg, 256 physical, R=8), or (b) add a smaller pool kernel (e.g. 3×3) so adjacent bits don't alias.

### 4.3 Structure of the lost `generate_svd_figure.py`
Rough shape — rewrite on 5090 as needed:
1. Load controller from `checkpoints_tifs/hardening/dscsp_v5_final.pt`.
2. Generate ~100 clean diffusion images (or load from pool).
3. For each image, sample a random 256-bit payload, compute `delta = controller(image, payload)`.
4. Stack all `delta` tensors into `(N, 3, 256, 256)`; reshape to `(N, 3*256*256)`.
5. Run batched SVD → keep top 3 left-singular vectors, reshape back to `(3, 3, 256, 256)`.
6. Normalize each singular-vector image to [0, 1] and save a 3-panel PNG/PDF to `figures/svd_singular_vectors.pdf`.
7. Also print the top-32 singular values + Gini coefficient. Gini > 0.7 = periodic/grid artifact (matches SPECTRUM analysis in `outputs_v5_analysis/security_analysis.json`).

### 4.4 The lost `real_jpeg_ste` edit to `dscsp/augmentations/differentiable.py`
Add this near the top-level of the file:

```python
def real_jpeg_ste(x: torch.Tensor, quality: int) -> torch.Tensor:
    """Real libjpeg JPEG round-trip with straight-through gradient.

    Forward: PIL.Image encode at `quality`, decode back. Range-in/range-out [-1, 1].
    Backward: identity (STE).
    """
    import io
    from PIL import Image
    import numpy as np

    with torch.no_grad():
        # [-1,1] -> [0,1] -> uint8 HWC
        imgs = ((x.detach().clamp(-1, 1) + 1.0) * 127.5).round().clamp(0, 255).to(torch.uint8)
        imgs = imgs.permute(0, 2, 3, 1).cpu().numpy()  # (B, H, W, 3)
        out = np.empty_like(imgs)
        for i, arr in enumerate(imgs):
            buf = io.BytesIO()
            Image.fromarray(arr).save(buf, format="JPEG", quality=int(quality))
            buf.seek(0)
            out[i] = np.array(Image.open(buf).convert("RGB"))
        y = torch.from_numpy(out).to(x.device).permute(0, 3, 1, 2).float()
        y = (y / 127.5) - 1.0   # back to [-1, 1]

    # STE: value = y, gradient = identity w.r.t. x
    return x + (y - x).detach()
```

Then in `AttackLayer._apply_single` (the `elif atk == "jpeg":` branch), insert before the `DiffJPEG` call:

```python
real_prob = float(self.config.get("real_jpeg_prob", 0.0) or 0.0)
if real_prob > 0.0 and self.training and torch.rand(1).item() < real_prob:
    q = int(torch.randint(int(self.config["jpeg_quality_range"][0]),
                          int(self.config["jpeg_quality_range"][1]) + 1, (1,)).item())
    return real_jpeg_ste(x, q)
```
